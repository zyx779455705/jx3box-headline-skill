# JX3BOX 头条文章规则提炼

本文件把三篇教程整理成执行规则。内容为转述和归纳，不复制原文。技能运行时以这里的规则为准；需要核对图例或上下文时再访问原文章。

## 一、画布与中心安全区

魔盒头条支持两套等比例尺寸：

| 模式 | 画布 | 比例 | 关键文字安全宽度 | 安全区横坐标 |
|---|---:|---:|---:|---:|
| 标准 | 1600×280 | 40:7 | 约 580 px | x=510 到 x=1090 |
| 高清 | 3200×560 | 40:7 | 约 1160 px | x=1020 到 x=2180 |

头条还会用作文章封面，左右内容在不同入口或裁切环境中可能不可见。因此：

- 主标题、副标题、作者和必要署名全部放进中心安全区。
- 背景、人物边缘、纹理、装饰线和纯氛围元素可以延伸到左右两端。
- 不把安全区误解为“所有内容只能在中间”。视觉可以全幅，信息必须居中。
- 设计高清版时按 3200×560 工作；需要标准版时等比缩小到 1600×280，并再次复核小字。
- 安全区规则是硬约束，不因构图风格改变。

## 二、主标题与副标题

### 2.1 主标题先压缩

教程强调主标题越精炼，就越能放大并让读者立即明白主题。执行时：

1. 从长标题中找出唯一的文章对象和核心动作，例如“明尊”“入门”“攻略”。
2. 主标题通常控制为 2–8 个汉字，优先使用明确名词或“对象+类型”的结构。
3. 将“手把手、从入门到进阶、适用版本、详细讲解”等承诺移到副标题。
4. 不为了短而丢失门派、玩法、版本或结论；有歧义时宁可多一个字。
5. 不制造原文没有的效果承诺、排名、数据或作者身份。

示例结构：

```text
长标题：从入门到进阶手把手教你的超级明尊T攻略
主标题：明尊攻略
副标题：从入门到进阶的实战指南
```

### 2.2 文字层级

信息优先级固定为：

```text
主标题 > 副标题/性质说明 > 作者 > 素材署名/辅助英文
```

- 主标题承担第一眼识别，不让作者行或英文装饰抢层级。
- 副标题补全范围与性质，不重复主标题原词。
- 没有副标题时，可以用作者、拼音或短英文补节奏，但必须有实际作用。
- 辅助英文不应伪装成信息，不堆无意义的长句。

## 三、字体与字形

### 3.1 授权

- 优先使用开放许可、已购买授权或用户明确有权使用的字体。
- 有付费内容、出售资源、打赏可见、商单或其他金钱流通时，按商业场景核验字体许可。
- 不把系统预装等同于可再分发或可商业使用；教程特别提醒不要把微软雅黑当默认开放字体。
- 记录字体名、授权类型、许可来源和是否允许商业使用。
- 无法核验时先用明确开放许可的替代字体，不在成品中赌授权。

### 3.2 排列优先于改字

大多数头条不需要重造字形。先按下列顺序解决：

1. 调整字距，让松散文字更紧凑。
2. 缩短或替换过长标题。
3. 一行装不下时改为两行，并控制行间距。
4. 放大主标题，缩小副标题和作者。
5. 用大小变化、明暗变化、局部强调色或双层背字建立层级。
6. 再考虑变形、拆笔、拼接或自绘元素。

### 3.3 改造字形的边界

教程展示了从原字笔画取材和自绘元素两种路径。采用时：

- 先观察字体原有的粗细、起收笔、倾斜和速度感，新增笔画要遵循同一逻辑。
- 左右结构、重心、笔画连接和负空间必须仍然可读。
- 可以延长横线、替换不合适的笔画或让相邻字互相借形，但不能把关键字变成伪字。
- 字形改造更接近标志或水印设计，不是每张攻略头条的必需步骤。
- 最终逐字核对，特别是生成式工具容易产生的中文伪字。

## 四、居中组合与对齐

“居中”指信息落在中心安全区，不等于所有元素机械地同轴排列。

可用方法：

- 调整字距后放入主标题。
- 用不同字号的副标题、作者或拼音形成长短节奏。
- 用破折号、居左/居右的小字建立隐形对齐线。
- 让局部放大的字与左右文字形成“长—短—长”或其他明确节奏。
- 用细线、框、几何块显式强调对齐，也可以仅靠边缘形成看不见的线。
- 设计逐渐复杂后若仍不清晰，回到最简洁的初稿往往更好。

判断标准不是“元素多”，而是标题区看起来有完整边界、层级稳定、留白有意图。

## 五、三种图文构图

### 5.1 直接图文

适合有完整背景、人物特写或官方宣传图式素材。

执行顺序：

1. 先把标题放到中心安全区。
2. 根据背景选择黑字或白字，检查大面积明暗冲突。
3. 必要时压暗或提亮局部背景，而不是只堆文字效果。
4. 再按需加入投影、内外发光、描边或渐变。
5. 若仍然空洞，用局部图形、人物特写、浅色背字或副标题破局。

风险：最省时，也最容易变成“把字放在图上”。文字排列和与背景的关系决定成败。

### 5.2 流线素材

适合没有强主图，或科技、试炼、数据、动作等需要动势的主题。

执行顺序：

1. 选 2–4 种形状或纹理素材，先确定主方向。
2. 用一条主线建立阅读方向，斜线通常比完全水平更有运动感。
3. 加标题和作者，再用透明度更低的辅线制造层次。
4. 箭头、线条和倾斜方向必须一致；避免互相打架。
5. 周边可以更复杂，中心标题必须更简洁，利用“周围繁、中心净”聚焦。
6. 填补四角空白时仍要服从主方向，不做随机贴纸墙。

### 5.3 人物与文字穿插

适合有清晰人物、武器、衣摆或其他可形成前后关系的轮廓。

执行顺序：

1. 先独立完成背景和标题，确认没有人物也能读。
2. 分析人物朝向、前后肢体、武器杆线和视觉重心。
3. 用蒙版让部分人物在字前、部分字在人物前，形成“前—后—前”层次。
4. 利用武器、衣摆或身体倾斜与字的笔画/空隙互动。
5. 用投影或发光强化层次，但不遮掉关键笔画。
6. 最后加框和小装饰，收束焦点。

风险：穿插很容易牺牲可读性。关键字义和人物脸永远优先。

## 六、文字迭代技巧

技巧篇的核心不是固定滤镜，而是逐项诊断：

| 症状 | 优先修正 |
|---|---|
| 字距松散 | 收紧字距，重新判断整体轮廓 |
| 标题太长 | 缩短、替代、分两行 |
| 标题太小 | 放大主标题，移走细节信息 |
| 单层发空 | 加浅背字、第二层、局部强调色 |
| 纯黑/纯白单调 | 从画面提取灰阶或强调色，保持对比 |
| 文字枯燥 | 加副文，并让主字奔放、小字工整形成对比 |
| 黑背景字不清 | 先换白字，再加克制的暗投影/发光 |
| 文字挡主体 | 调整文字位置、大小或层级，给主体让位 |
| 科技感不足 | 加克制的小英文、网格或几何层，不改变核心语言 |
| 画面刺眼 | 降低装饰透明度和饱和度，保留主标题对比 |
| 动感不足 | 沿动作或武器方向做模糊/涂抹，并让轨迹闭合或收束 |

每轮只解决一个主要问题，比较修改前后。不要同时改字体、颜色、构图和背景，以免无法判断改善来自哪里。

## 七、主体、背景与融合

- 先找到图片主体和最能体现主题的特征，再定文字位置。
- 深色背景优先测试白字，浅色背景优先测试黑字；这只是起点，不是绝对规则。
- 人物脸、眼睛、武器动作和重要环境信息不被主标题无意义覆盖。
- 可用局部压暗、半透明底、投影、描边、发光和渐变提高识别性。
- 背景纹理与文字风格要匹配：庄严内容偏工整和素色；强调速度或动作时可用倾斜、描边、阴影和动势图；现代/异域主题再选择相符元素。
- 图形和效果必须解释得通：方向、层次、焦点和留白都有用途。

## 八、颜色规则

- 从主图提取主色、辅色和强调色，或使用成熟色卡。
- 主色维持整体，辅色区分层次，强调色只用于关键笔画或信息。
- 先保证文字与背景的亮度差，再谈色相高级感。
- 不因为某颜色流行或被称为“高级”就直接拼配；两个强色同时抢眼会破坏层级。
- 25% 缩放时，强调色仍应帮助识别而非制造噪点。

## 九、版权与署名

教程要求寻找原作者、检查发布说明并标出来源。本技能增加更严格的闸门：

1. 确认作者和原始发布页，不能只引用二次搬运站。
2. 确认许可或取得明确同意；没有禁止声明并不自动构成授权。
3. 出现“禁止二改、禁止使用、私人稿件、商用稿件、商单”等限制时不得使用。
4. 商业场景还要确认许可是否允许商业使用。
5. 署名需实际可读，可放在次级位置，但不能缩成看不见的像素。
6. 将作者、来源 URL、许可/同意依据、商业权限和署名文字写入设计简报。

可接受状态：用户自有、明确许可、已购买许可、开放许可、公版。

必须拦截：来源不明、作者不明、许可不明、明确禁止、商业权限与实际用途冲突。

## 十、成品验收

成品发布前逐项确认：

- [ ] 画布为 3200×560 或 1600×280。
- [ ] 主标题、副标题、作者和必要署名均在中心安全区。
- [ ] 主标题通常为 2–8 个汉字，长而不必要的信息已下放。
- [ ] 100% 和 25% 缩放均可读。
- [ ] 中文逐字正确，无生成伪字、漏字或异体误用。
- [ ] 画面主体未被无意义遮挡，图文有明确前后关系。
- [ ] 构图只围绕一个主模式，效果服务于可读性和主题。
- [ ] 图片、字体和素材授权记录完整，署名可读。
- [ ] 无法核验的素材已经替换，而不是只加一句“侵删”。
