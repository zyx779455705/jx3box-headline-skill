# JX3BOX 头条执行指南

## 1. 输入简报模板

将用户输入整理成以下 JSON。`source_assets` 为空时，技能可生成原创背景；不代表可以随意抓取网络图片。

```json
{
  "article_title": "从入门到进阶手把手教你的超级明尊T攻略",
  "main_title": "明尊攻略",
  "subtitle": "从入门到进阶的实战指南",
  "author": "作者名",
  "resolution": "high",
  "composition_mode": "auto",
  "subject_position": "left",
  "layering_requested": false,
  "commercial_context": false,
  "font": {
    "name": "已选字体名",
    "rights_status": "open",
    "commercial_allowed": true,
    "source": "字体官方许可页"
  },
  "source_assets": [
    {
      "label": "用户游戏截图",
      "creator": "用户本人",
      "source": "本次会话附件",
      "rights_status": "owned",
      "commercial_allowed": true,
      "attribution": ""
    }
  ],
  "notes": "庄严、克制，不要花哨"
}
```

允许的 `resolution`：`high`（3200×560）或 `standard`（1600×280）。

允许的 `composition_mode`：

- `auto`：按素材自动选择。
- `direct`：直接图文。
- `flow`：流线素材。
- `interlock`：人物与文字穿插。

允许的素材/字体 `rights_status`：

- `owned`
- `explicit-permission`
- `licensed`
- `open`
- `public-domain`
- `unknown`
- `prohibited`

运行校验：

```powershell
python scripts/headline_brief.py --input brief.json --output validated-brief.json
```

脚本退出码为 0 只表示输入结构有效；是否可以进入成品由输出中的 `ready_for_render` 决定。

## 2. 构图决策

```text
有明确人物/武器轮廓，且用户希望前后层次？
  是 -> interlock
  否 -> 背景本身是否足够强、主题是否清楚？
          是 -> direct
          否 -> flow
```

### direct 设计骨架

```text
全幅背景或特写
    ↓ 局部压暗/提亮
中心安全区：主标题
    ↓
副标题 + 作者
    ↓
必要时浅背字/人物特写/小图形破局
```

适合：外观图、风景图、完整游戏截图、人物特写、庄严白皮书。

### flow 设计骨架

```text
统一主方向（例如左下 -> 右上）
主线 + 低透明辅线 + 箭头/框
外围复杂，中心简洁
主标题保持最大对比
```

适合：科技、试炼、数据、技能循环、无强主图的攻略。

### interlock 设计骨架

```text
背景层
标题后层
人物主体层
标题前层/关键笔画
投影/发光层
框和小装饰层
```

适合：人物立绘、武器斜线明显、动作方向清楚的画面。

## 3. 精确坐标

### 高清 3200×560

- 画布：`x=0..3200, y=0..560`
- 关键文字安全区：`x=1020..2180, y=0..560`
- 建议主标题中心：`(1600, 245)` 左右，根据副标题上下调整。
- 建议主标题最大视觉宽度：不超过 1080 px，留出安全余量。
- 建议副标题/作者：中心安全区内，距边缘至少 40 px。

### 标准 1600×280

- 画布：`x=0..1600, y=0..280`
- 关键文字安全区：`x=510..1090, y=0..280`
- 建议主标题中心：`(800, 122)` 左右。
- 建议主标题最大视觉宽度：不超过 540 px。
- 建议副标题/作者：中心安全区内，距边缘至少 20 px。

这些是起始坐标，不是要求所有标题机械同轴。任何偏移都不能让关键信息越出安全区。

## 4. 图像生成提示词结构

生成式图像工具只负责背景、人物氛围或素材，不负责最终中文标题。

```text
目标：为 JX3BOX 剑网3攻略制作超宽横幅背景，比例 40:7。
主题：<门派/副本/攻略主题>。
构图：<direct/flow/interlock 对应描述>。
主体：<人物/武器/场景>位于<左/右/两侧>，中心保留清晰低噪声区域。
色彩：<主色>、<辅色>，用<强调色>点缀，保持文字区高对比。
动势：<方向>，线条、粒子和模糊遵循同一方向。
限制：不要生成任何文字、汉字、字母、徽标、水印或边框外裁切；不要把人物脸放在中心文字安全区。
```

如果用户给了原图，编辑提示必须写清保留项：人物身份、服饰、脸、武器、动作、原始授权和不可改区域。

## 5. 排版顺序

1. 将无字背景导入精确编辑工具。
2. 标出中心安全区辅助线，导出前隐藏。
3. 放主标题，先只做黑/白高对比版本。
4. 调字距、大小、换行和边缘对齐。
5. 放副标题和作者，建立层级。
6. 根据背景加最少量的投影、描边、发光或半透明底。
7. 如需穿插，复制标题层并用蒙版分成前后两层。
8. 放素材署名，确认可读但不抢主标题。
9. 100% 和 25% 缩放复核中文和层级。

## 6. 现有头条改稿

改稿先诊断，不整张重做：

| 问题 | 最小改动 |
|---|---|
| 主标题散 | 收字距、缩短、重排，不先换背景 |
| 主标题不够大 | 下放副信息，扩大主标题 |
| 背景抢字 | 局部压暗/模糊或加半透明底 |
| 人物被遮 | 移动标题或重做前后蒙版 |
| 颜色脏 | 回到画面主色，保留一个强调色 |
| 太空 | 加副标题、浅背字或有方向的装饰 |
| 太满 | 删除无功能装饰，恢复中心留白 |
| 中文错字 | 删除生成文字，用精确排版重做 |

每次改一类问题，保存对比版本。只在版式方向错误时整体重构。

```markdown
主标题：明尊攻略
副标题：从入门到进阶的实战指南

```

```markdown
无字背景：`<absolute-path>`
待排文字：<主标题/副标题/作者>
版式：<坐标、字号比例、对齐和颜色>
原因：当前宿主没有可验证的精确中文排版能力，未将生成伪字当作成品。
```
